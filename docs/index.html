Fresh VM → ready shell in minutes

Stop rebuilding your terminal by hand.

ShellDeck is a cross-platform shell bootstrap for Windows, Linux and macOS. It installs your command-line toolkit, configures PowerShell, Bash or Zsh, manages SSH workflows, and can turn a machine into a lightweight homelab control node.

Built for people who constantly rebuild machines.

Dotfiles are useful, but they do not install dependencies, configure SSH, choose a machine profile, or prepare an infra dashboard. ShellDeck packages the whole setup flow into one installer.

Cross-platform bootstrap

Prepare Windows, Linux and macOS environments with one project and profile-aware installers.

PowerShell, Bash and Zsh

Hook a shared runtime into your shell profile while keeping each platform native.

Modern CLI toolkit

Install and check common tools like fzf, bat, eza, zoxide, starship, ripgrep, jq, gh and more.

SSH host workflow

Add hosts, store shortcuts, launch connections, and manage a small infra inventory.

Homelab control node

Optionally enable an infra dashboard for Proxmox, Docker VMs, NAS devices and app servers.

Safer updates

Refresh ShellDeck while preserving aliases, custom functions, SSH config, hosts and profile data.

One-command install

Tagged install URLs are recommended for production. Use the latest release tag when you want a reproducible setup.

Windows PowerShell

irm https://raw.githubusercontent.com/adrienclaire/ShellDeck/v0.2.3/install.ps1 -OutFile install.ps1
.\install.ps1

Linux / macOS

curl -fsSLO https://raw.githubusercontent.com/adrienclaire/ShellDeck/v0.2.3/install.sh
bash install.sh
